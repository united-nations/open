# Monetary time-series display

CPI/inflation adjustment is disabled. Financial charts display nominal source USD,
consistent with the current CEB methodology in
[data/ceb-methodology.json](../data/ceb-methodology.json).

The previous US CPI proxy, adjusted-USD controls and conversion instructions no
longer describe an active portal feature. Amounts, signs and source gaps remain
as reported. Reintroducing a real-value display would require a separate decision
about the deflator, coverage, labels and calculation; it must not silently alter
source data or nominal controls.
